How this actually works

No signup, no server round-trip, and nothing you enter leaves your device. The model itself runs as plain JavaScript in this page.

1

Trained on real field data

A random forest model was trained on an open agricultural dataset of soil and climate readings paired with the crop that performed best under those conditions.

2

Converted to run client-side

The trained model was compiled directly into JavaScript, so predictions happen instantly in your browser instead of calling a remote API.

3

Weather pulled live, on request

Choosing "use live weather" fetches your current temperature and humidity from Open-Meteo's public forecast API for the coordinates you allow.
